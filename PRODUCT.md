# Спроси конспект

Пользователь: студент — задаёт 3–10 вопросов в неделю, чаще всего перед зачётом;
преподаватель — заходит раз в день проверить и поправить ответы ИИ.

Зачем: получить понятный ответ по своему конспекту, не перечитывая 60 страниц.

Ключевой сценарий: преподаватель вносит конспект по предмету → студент задаёт
вопрос по этому предмету → ИИ отвечает строго по тексту конспекта → преподаватель
проверяет ответ и отмечает «проверено» → студент видит проверенный ответ.

Экраны:
1. Вход и выбор роли.
2. Лента вопросов: студент видит только свои, преподаватель — все.
3. Новый вопрос с ответом ИИ.
4. Проверка ответа преподавателем.
5. Материалы: конспекты по предметам (только преподаватель).

Основная сущность: `вопрос` — предмет, текст вопроса, ответ ИИ, статус
(новый / отвечен / проверен), автор, дата создания.

Роли: две.
- Студент: создаёт вопросы, читает свои ответы и отметку «проверено», чужие не видит.
- Преподаватель: видит все вопросы, вносит конспекты, правит ответ, меняет статус.

LLM-функция: одна — ответ на вопрос по тексту конспекта выбранного предмета.
Если в конспекте ответа нет, ИИ обязан сказать «в материале этого нет», а не
додумывать. Каждый ответ сохраняется и доступен для проверки человеком.

Не в этом курсе: платежи и подписки, вход через соцсети, мобильное приложение,
чат в реальном времени, загрузка файлов (конспект вносится текстом), экспорт в PDF.

До 400 слов. Две роли, одна LLM-функция, без платежей и лишних интеграций.
